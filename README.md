mend: one patch tool for every AI edit format. It reads a patch in unified diff, SEARCH/REPLACE blocks, V4A, or JSON edits, finds the lines each edit names at the first of three matching tiers, and writes every change or none. `SPEC.md` is the whole specification.

## Run it

```sh
node main.ts [options] [PATCH]
```
